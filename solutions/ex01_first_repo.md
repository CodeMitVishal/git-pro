# Solution · Exercise 1: Your first repository

Run these commands inside `playground/ex01` (after `bash exercises/ex01_first_repo/setup.sh`). Try it yourself first!

```bash
git init
git config --local user.email "vishal@example.com"
git add README.md hello.py
git status --short
git commit -m "Add hello app"
git log --oneline
```

Then check:

```bash
bash exercises/ex01_first_repo/check.sh
```

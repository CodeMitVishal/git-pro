# Exercise 1 · Your first repository

[← Course](../../README.md)

## 1. Create the practice repository

Open **Git Bash** (Windows) or a terminal in the course folder:

```bash
bash exercises/ex01_first_repo/setup.sh
```

## 2. Your task

```text
In playground/ex01 there are three files: README.md, hello.py and notes.txt.

  1. Turn the folder into a Git repository.
  2. Set YOUR email for this repository only (git config --local user.email ...).
  3. Make ONE commit that contains README.md and hello.py, but NOT notes.txt.
     Message: "Add hello app"
```

## 3. Check your work

```bash
bash exercises/ex01_first_repo/check.sh
```

It prints what's still missing, or **All checks passed!**

Stuck? See the [solution](../../solutions/ex01_first_repo.md).

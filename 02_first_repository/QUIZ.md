**1. What are Git's three areas?**
- A) main, dev, prod
- B) working tree, staging area (index), repository
- C) local, global, system
- D) add, commit, push

**2. What does git add do?**
- A) Saves a commit
- B) Copies changes into the staging area for the next commit
- C) Uploads to GitHub
- D) Creates a file

**3. git status --short shows '?? notes.txt'. What does it mean?**
- A) Deleted
- B) Untracked: Git sees it but doesn't track it
- C) Conflict
- D) Staged

**4. You edited app.py after 'git add app.py'. What does git commit save?**
- A) The newest version
- B) The version that was staged
- C) Nothing
- D) Both versions

**5. Which command shows staged changes?**
- A) git diff
- B) git diff --staged
- C) git log -p
- D) git show

**6. What does 'git commit -am msg' do?**
- A) Commits all files including untracked ones
- B) Stages modified TRACKED files and commits them
- C) Amends the last commit
- D) Adds a remote

**7. A file is in .gitignore but still shows as modified. Why?**
- A) The pattern is wrong
- B) It was already tracked before; run git rm --cached
- C) Git ignores .gitignore on Windows
- D) It needs a restart

**8. Which pattern ignores every log file?**
- A) log
- B) *.log
- C) /log/
- D) !*.log

**9. What does '!keep.log' in .gitignore mean?**
- A) Ignore keep.log
- B) Exception: do NOT ignore keep.log
- C) Delete keep.log
- D) A comment

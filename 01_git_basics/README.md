# Module 1 · Git basics: why and setup

[← Back to the course](../README.md) · [Slides](../slides/modules/Module-01.pdf) · [Interview Q&A](INTERVIEW.md)

What version control is, why every team uses Git, and how to install and configure it.

## Lessons

Every lesson runs real Git commands in a throwaway sandbox and prints them with their output. Your own repositories are never touched.

| Lesson | File | Key idea |
|---|---|---|
| Why version control | [`01_why_version_control.py`](01_why_version_control.py) | snapshots, history, compare and go back |
| Install & configure | [`02_install_and_config.py`](02_install_and_config.py) | user.name/email, config levels, help |

```bash
python 01_git_basics/01_why_version_control.py
```

## Exercise: Your first repository

Turn a folder into a repository, set your local email, and make a first commit with the right files.

python exercises/ex01_first_repo.py setup

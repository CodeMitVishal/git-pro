# Interview prep

[← Back to the course](../README.md)

Git comes up in almost every developer interview, often as "tell me about your workflow" or a "what would you do if..." scenario. Everything you need is here.

| Resource | What's inside |
|---|---|
| [**Top 50 questions**](TOP_50.md) | 50 short answers, each linked to the module with full examples |
| [**Cheat sheet**](cheat_sheet.md) | every command from the course on one page |
| Module interview pages | every module has an `INTERVIEW.md` with model answers and follow-ups |
| [Scenario questions](../12_capstone/INTERVIEW.md) | "committed to main", "lost commits", "pushed a secret", "set up a team repo" |

## How to use it

1. Read the Top 50 and mark the ones you can't answer in one breath.
2. For each marked one, open its module, **run the lesson**, and redo the exercise.
3. **Answer out loud.** Explain the *why* ("revert, because main is shared"), not just the command.
4. Prepare one **story** from a real project: a conflict you resolved, a bug you found with bisect, or a workflow you improved.
